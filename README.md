# dsh-feiyu-mood ｜ 鱼的心情

> 给 AI 伙伴一个**会自己判断、你看得见**的心情。
>
> 不是关键词硬猜，也不是随机数 —— 每轮聊完，用 DSH 自己的模型判一次"这一轮她的心情往哪走"，
> 心情会慢慢起伏、也会慢慢回稳，像活人。

## 它做什么

- **每轮聊完判一次**：这一轮里她开心了、心疼了、还是有点失落，判完写进心情值 + 七根情绪
- **心情是全局一份**：跨会话共享，属于"这个人"，不属于某个会话
- **会衰减**：心情向基线慢慢回落（半衰期约 3 小时），七根情绪衰减更快（约 90 分钟）
- **会注入对话**：把「此刻心情」塞进 system prompt 的 context 段，影响她这一轮的口气 ——
  用 context 而不是改系统提示，**不动 DSH 的前缀缓存**
- **右下角挂饰**：点开看数值 + 七根情绪 + 完整时间线，五档表情跟着心情换
- **设置页「鱼的心情」**：称呼、目标会话、开关、基线/下限、一键重置

## 判断口径（谁在说话，决定怎么判）

| 这一轮是谁发起的 | `source.kind` | 判什么 |
|---|---|---|
| 你本人在说话 | `user` | 你这话怎么影响她 |
| **她自己主动来找你** | `speak-up` | 她自己的心意（想你的甜、惦记你的心焦），不算"干活" |
| 定时任务叫她干活 | `bili-duty-scan` | 她自己干活时的心情 |
| 宿主每轮塞的上下文 | `runtime-context` / `time-context` | **跳过**，不当成"谁说的话" |

判出来**一点变化都没有**的回合不会进时间线 —— 记录里只留真有过心情波动的。

## 装

```bash
dsh plugin --profile desktop add github:Yuuyuko-uu/dsh-feiyu-mood
```

> 暂未发布到 npm；上架后可简写成 `dsh plugin add dsh-feiyu-mood`。

装完**必须重启一次 DSH**（插件在 bundle 层组装，不重启不生效）。

## 首次使用

1. 重启后进 **设置 → 鱼的心情**
2. 填两个称呼：「TA 叫什么」（被关心的那个人）、「TA 自己叫什么」（有心情的那个人）
3. 在「在哪个会话里生效」里选一个会话 —— 只有这个会话里会判断和注入
4. 跟 TA 聊两句，回到这一页看心情有没有动；右下角的挂饰也会跟着变

## 设置项

| 项 | 说明 |
|---|---|
| 当前心情 | 五档表情 + 数值 + 标签 + 最后一条理由；右边「重置到基线」 |
| 称呼 | 两个名字，会写进判断提示词 |
| 在哪个会话里生效 | 下拉列出真实会话（跳过归档和空会话），换完立刻切 |
| 每轮判断心情 | 关掉就完全不判断、不改数值 |
| 把当前心情注入对话 | 关掉她就不会被心情影响口气（挂饰照常显示） |
| 基线心情 / 心情下限 | 没情绪时回落到多少；最低能掉到多少（0 = 不设底线） |
| 完整记录 | 最近 40 条：时间 / 心情 / 变化 / 理由 |

改设置**立刻生效**，不用重启。

## 多少钱

每轮判断是一次**很短**的模型调用（system 提示约 600 token，加本轮对话摘要），用你当前会话所用的 provider/model。
一天聊几十轮也就几分钱；嫌贵就把「每轮判断心情」关掉。

## 换掉示例图片

`assets/` 里是五档表情 + 一张形象图（`feiyu.png`），换成你自己的图就行，文件名保持不变：

```
face-great.png  心情 ≥ 80
face-good.png   62–79
face-ok.png     42–61
face-worry.png  25–41
face-sad.png    < 25
```

## 数据在哪

`<DSH_HOME>/feiyu-mood/`：

- `state.json` —— 当前心情、七根情绪、时间线
- `config.json` —— 设置
- `diag.log` —— 判断日志（哪一轮、判成什么、为什么没记）

**不上传任何地方。**
